# WHITELINE · Android Icon Pack

Здесь публикуются **только готовые APK и OTA-манифесты** приложения WHITELINE. Исходный код находится в отдельном закрытом репозитории и не публикуется здесь.

## Установка и OTA

- [Последний релиз](https://github.com/INFEND/WHITELINE-RELEASES/releases/latest)
- [APK](https://github.com/INFEND/WHITELINE-RELEASES/releases/latest/download/WHITELINE-ICON-PACK.apk)
- [OTA-манифест](https://github.com/INFEND/WHITELINE-RELEASES/releases/latest/download/update.json)

Встроенный OTA-клиент проверяет номер версии, скачивает APK внутри WHITELINE, проверяет его размер и SHA-256 и открывает системный установщик Android. Переход в браузер или ввод GitHub-токена не нужен. Установка или разрешение Android на установку из этого источника может потребовать подтверждения.

### Коллекция иконок

Публичный APK включает только ресурсы, разрешённые к распространению. Купленные пользователем изображения сторонних наборов **не распространяются** в этом репозитории и могут храниться только в личной коллекции на его устройстве.

Релиз подписывается постоянным ключом WHITELINE. Проверка SHA-256 публичного APK и наличия сторонних растровых изображений включена в CI.
